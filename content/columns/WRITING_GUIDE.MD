# 100일 컬럼 문체/전개 가이드 (Day 1 최종본 기준)

이 문서는 `/Users/ykkim/Desktop/Homepage/content/columns/posts/hifi-headfi-100days-day1.md`의 첨삭본을 기준으로 추출한 작성 규칙이다.  
Day 2 이후 원고는 아래 기준을 기본값으로 사용한다.

## 1) 문체 톤
- 기본 톤은 친절한 설명형 + 대화형 어조를 섞는다.
- 단정적 명령문보다 제안형 표현을 우선한다.
  - 예: `~입니다` + `~해 보려 합니다` + `~일 수 있습니다`
- 독자를 직접 호명하지 않더라도, 독자 상황을 먼저 인정하는 문장으로 시작한다.
- 결론을 먼저 제시하고, 바로 이유를 붙인다.

## 2) 용어 운용
- 핵심 용어는 한글 표기 중심으로 쓰고, 필요 시 영문/약어를 병기한다.
  - 예: 하이파이(Hi-Fi), 헤드파이(Head-Fi), 왜곡(THD/IMD)
- 기술 용어는 처음 등장할 때 1회 짧게 정의한다.
- 업계에서 실제로 통용되는 표현과 개념 정의가 다를 때는 둘 다 알려준다.
  - 예: `개념적으로는 A지만, 실사용에서는 B로도 쓰입니다.`

## 3) 내용 전개 방식
- 섹션 흐름은 고정한다.
  1. 오늘의 질문
  2. 핵심 개념 3개
  3. 공학적으로 이해하기
  4. 청취 경험/인문학적 관점
  5. 실전 예시
  6. 앞으로의 학습 흐름
  7. 마무리
- 각 대단락은 `요점 1문장 -> 풀어서 설명 -> 짧은 예시` 순으로 전개한다.
- 같은 주장도 `원리 -> 현실 적용 -> 독자 행동` 순으로 연결한다.

## 4) 설득 방식
- 공학적 설명만으로 닫지 않고, 실제 사용 맥락(환경/착용/취향)을 반드시 붙인다.
- "정답 강요"를 피하고 "판단 기준 제공"으로 마무리한다.
- 과장 표현 대신 조건부 표현을 사용한다.
  - 예: `~일 가능성이 큽니다`, `~하는 경우가 많습니다`

## 5) 문장 길이/리듬
- 핵심 정의 문장은 짧게, 설명 문장은 중간 길이로 유지한다.
- 3문장 이상 이어질 때는 목록으로 전환해 가독성을 높인다.
- 문단 끝에는 다음 문단으로 넘어가는 연결 문장을 1개 넣는다.

## 6) 시리즈 연결 규칙
- 이전/다음 Day를 본문에서 명시적으로 연결한다.
- 다음 Day에 넘길 내용은 `여기서는 범위만 소개`한다고 선을 긋는다.
- 당일 주제 범위를 벗어나는 심화 설명은 금지한다.

## 7) 품질 체크리스트 (작성 직후)
- 공학 개념과 주관적 견해가 분리되어 있는가
- 초보 독자가 처음 읽어도 흐름을 따라갈 수 있는가
- 용어 첫 등장 정의가 들어갔는가
- 실전 예시가 최소 1개 이상 들어갔는가
- 다음 Day 연결 문장이 있는가
