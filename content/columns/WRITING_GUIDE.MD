## 1) 문체 톤
- 기본 톤은 친절한 설명형 + 대화형 어조를 섞는다.
- 단정적 명령문보다 제안형 표현을 우선한다.
  - 예: `~입니다` + `~해 보려 합니다` + `~일 수 있습니다`
- 독자를 직접 호명하지 않더라도, 독자 상황을 먼저 인정하는 문장으로 시작한다.
- 결론을 먼저 제시하고, 바로 이유를 붙인다.
- 반문형 문장을 적절히 사용해 독자의 사고를 유도한다.
  - 예: `정말 그럴까요?`, `그렇다면 무엇이 기준일까요?`

## 2) 용어 운용
- 핵심 용어는 한글 표기 중심으로 쓰고, 필요 시 영문/약어를 병기한다.
  - 예: 하이파이(Hi-Fi), 헤드파이(Head-Fi), 왜곡(THD/IMD)
- 기술 용어는 처음 등장할 때 1회 짧게 정의한다.
- 업계에서 실제로 통용되는 표현과 개념 정의가 다를 때는 둘 다 알려준다.
  - 예: `개념적으로는 A지만, 실사용에서는 B로도 쓰입니다.`

## 3) 내용 전개 방식
- 섹션 흐름은 고정한다.
  1. 오늘의 질문
  2. 핵심 개념 3개
  3. 공학적으로 이해하기
  4. 청취 경험/인문학적 관점
  5. 실전 예시
  6. 앞으로의 학습 흐름
  7. 마무리
- 각 대단락은 `요점 1문장 -> 풀어서 설명 -> 짧은 예시` 순으로 전개한다.
- 같은 주장도 `원리 -> 현실 적용 -> 독자 행동` 순으로 연결한다.
- 복합 개념은 비유를 1회 사용해 난도를 낮춘다.
  - 예: `기초 공학 위에 취향이라는 건축물을 올린다`
- 독자가 바로 실행할 수 있는 점검 순서를 숫자 리스트로 제시한다.
  - 예: `1. 환경 점검 -> 2. 소스 정리 -> 3. 매칭 확인`

## 4) 설득 방식
- 공학적 설명만으로 닫지 않고, 실제 사용 맥락(환경/착용/취향)을 반드시 붙인다.
- "정답 강요"를 피하고 "판단 기준 제공"으로 마무리한다.
- 과장 표현 대신 조건부 표현을 사용한다.
  - 예: `~일 가능성이 큽니다`, `~하는 경우가 많습니다`
- 예외 케이스를 짧게 인정하고 기본 원칙으로 되돌아온다.
  - 예: `예외는 있지만 입문 단계에서는 기본 프레임을 우선한다`
- 이론만 말하지 말고 `예산/가성비` 같은 현실 제약을 함께 언급한다.

## 5) 문장 길이/리듬
- 핵심 정의 문장은 짧게, 설명 문장은 중간 길이로 유지한다.
- 3문장 이상 이어질 때는 목록으로 전환해 가독성을 높인다.
- 문단 끝에는 다음 문단으로 넘어가는 연결 문장을 1개 넣는다.
- 한 섹션에 1~2개의 강한 요약 문장을 배치해 기억 포인트를 만든다.
- 중간 이미지는 단락 전환 지점에 배치해 긴 본문의 호흡을 조절한다.

## 6) 시리즈 연결 규칙
- 이전/다음 Day를 본문에서 명시적으로 연결한다.
- 다음 Day에 넘길 내용은 `여기서는 범위만 소개`한다고 선을 긋는다.
- 당일 주제 범위를 벗어나는 심화 설명은 금지한다.

## 7) 품질 체크리스트 (작성 직후)
- 공학 개념과 주관적 견해가 분리되어 있는가
- 초보 독자가 처음 읽어도 흐름을 따라갈 수 있는가
- 용어 첫 등장 정의가 들어갔는가
- 실전 예시가 최소 1개 이상 들어갔는가
- 다음 Day 연결 문장이 있는가

## 8) Day 2에서 추가로 반영할 스타일 포인트
- `개념 설명 -> 왜 중요한지 -> 바로 적용 가능한 판단 순서`를 한 세트로 묶는다.
- 실전 예시에서는 결론형 문장으로 마무리한다.
  - 예: `정답을 찾기보다 용도에 맞게 고르는 것이 현명합니다.`
- 리뷰/평가 인용 시 `결론만 보지 말고 조건을 본다`는 메시지를 반복한다.
- 본문 중간 이미지는 단락 전환 지점에서 사용해 리듬을 만든다.

## 9) Day 3에서 추가로 반영할 스타일 포인트
- 용어는 초보자 친화적으로 선택한다.
  - 예: `트랜스듀서` 대신 문맥상 `리시버(헤드폰/이어폰/스피커)`처럼 풀어쓴다.
- 초보자 불안을 낮추는 문장을 중간에 배치한다.
  - 예: `지금은 이 순서만 기억해도 충분합니다.`
- 비교적 시의성 있는 비유(계주, 팀플레이 등)를 사용해 체인 개념을 쉽게 전달한다.
- 새 장비 구매 전 `현재 시스템 최적화`를 먼저 권장하는 실전 지침을 넣는다.
