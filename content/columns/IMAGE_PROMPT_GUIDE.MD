# 컬럼 이미지 생성 프롬프트 가이드

이 문서는 Hi-Fi/Head-Fi 컬럼용 이미지 생성 기준이다.  
목표는 **일관된 시각 톤 유지**와 **주제 전달력 강화**다.

## 1) 기본 원칙
- 매 컬럼은 총 4장으로 구성한다.
  - 커버 이미지 1장
  - 인서트 이미지 3장
- 모든 이미지는 **텍스트 없는 순수 일러스트**로 생성한다.
- 매 회차마다 주제는 달라도, 색감/광원/렌더링 톤은 통일한다.

## 2) 공통 스타일 프롬프트 (항상 고정)
아래 문장을 모든 이미지 프롬프트 맨 앞에 붙인다.

```text
오디오 전문 컬럼용 고급 디지털 일러스트, 반사실적+인포그래픽 하이브리드 스타일, 선명한 디테일, 깔끔한 구도, 시네마틱 조명, 깊은 네이비 배경, 청록(cyan)과 오렌지 포인트 광원, 은은한 마젠타 하이라이트, 부드러운 그라디언트, 과하지 않은 입체감, 프리미엄 테크 매거진 분위기, 교육적이지만 감성적인 무드, 높은 완성도, 통일된 시각 아이덴티티.
```

## 3) 공통 금지 프롬프트 (항상 고정)
아래 문장을 모든 이미지 프롬프트 맨 끝에 붙인다.

```text
이미지 내부에 글자, 숫자, 로고, 워터마크, 서명, UI 프레임, 아이콘형 텍스트 요소를 넣지 마세요. 문자처럼 보이는 흔적도 만들지 마세요. 얼굴/손/귀 형태 왜곡, 뭉개진 디테일, 과도한 노이즈, 저해상도 느낌을 피하세요.
```

## 4) 출력 규격 (항상 고정)
- 비율: `16:9`
- 권장 해상도: `1920x1080` 이상
- 스타일 일치 우선순위:
  1. 색상 체계 일치
  2. 광원/명암 일치
  3. 렌더링 질감 일치
  4. 구도 명확성

## 5) 커버 이미지 프롬프트 템플릿
커버는 해당 Day의 핵심 주제가 한눈에 보여야 한다.

```text
[공통 스타일 프롬프트]
[DAY 번호] 컬럼 커버 이미지. 주제: [주제 한 줄].
핵심 메시지: [독자가 한 문장으로 이해해야 할 포인트].
중앙에 상징 오브젝트 1개를 크게 배치하고, 주변 보조 요소 1~2개로 주제를 보강하세요.
시선을 중앙으로 모으는 구조, 과하지 않은 역동성, 깔끔한 배경 분리, 교육용 컬럼 표지에 적합한 명확한 전달력.
텍스트 없이도 주제가 분명히 보이도록 구성하세요.
비율 16:9.
[공통 금지 프롬프트]
```

## 6) 인서트 이미지 프롬프트 템플릿
인서트는 각각 다른 역할을 맡는다.

### 인서트 1: 개념 설명용
```text
[공통 스타일 프롬프트]
[DAY 번호] 컬럼 인서트 이미지 1.
개념: [핵심 개념 1].
한 장면에서 개념의 구조가 직관적으로 보이도록 표현하세요. (예: 비교, 흐름, 대비)
오디오 요소(파형, 스피커, 귀, 장치, 공간감 등)를 상징적으로 사용하고 배경은 단순하게 유지하세요.
텍스트 없이 순수 일러스트로 개념 전달이 가능해야 합니다.
비율 16:9.
[공통 금지 프롬프트]
```

### 인서트 2: 환경/메커니즘 설명용
```text
[공통 스타일 프롬프트]
[DAY 번호] 컬럼 인서트 이미지 2.
환경 또는 작동 원리: [핵심 개념 2 또는 청취 환경].
입력 -> 변화 -> 결과의 흐름이 시각적으로 느껴지게 구성하세요.
깊이감 있는 레이어와 빛의 흐름으로 메커니즘을 표현하되, 복잡도를 과도하게 높이지 마세요.
텍스트 없이 순수 일러스트로 원리 전달이 가능해야 합니다.
비율 16:9.
[공통 금지 프롬프트]
```

### 인서트 3: 예시/상황 적용용
```text
[공통 스타일 프롬프트]
[DAY 번호] 컬럼 인서트 이미지 3.
실전 예시: [예시 상황 한 줄].
사람의 청취 맥락(실내/실외, 집중 청취, 장비 비교 등)이 자연스럽게 드러나도록 구성하세요.
감성은 살리되 정보 전달력이 떨어지지 않게, 주제와 직접적으로 연결되는 장면으로 만드세요.
텍스트 없이 순수 일러스트로 예시 상황이 명확히 보이도록 하세요.
비율 16:9.
[공통 금지 프롬프트]
```

## 7) 빠른 작성용 입력 폼
프롬프트 생성 전에 아래 4줄만 먼저 채운다.

```text
DAY:
주제:
핵심 개념 3개:
실전 예시 2개:
```

## 8) 생성 후 체크리스트
- 커버만 봐도 그날 주제가 읽히는가
- 인서트 1/2/3이 각각 개념/원리/예시 역할을 분명히 나누는가
- 4장이 같은 시리즈처럼 보이는가 (색감/조명/질감 통일)
- 이미지 내부에 텍스트 흔적이 없는가
