# 원고 작성·정비 기준

## 새 글 작성

1. 제품 리뷰는 `content/reviews/_template.md`, 공간 리뷰는 `_space-template.md`, 기사는 `content/articles/_template.md`를 복사합니다. `_`로 시작하는 파일은 목록과 사이트맵에서 제외됩니다.
2. 파일명을 정하면 그 이름이 URL이 됩니다. 발행한 파일명은 제목을 고쳐도 변경하지 않습니다.
3. `title`에는 브랜드·제품명 또는 공간명을 정확히 적고, 글의 개성을 살린 부제를 붙입니다. 원래 말투를 획일화할 필요는 없습니다.
4. `excerpt`는 본문 첫 문단 복사 대신 글에서 확인할 수 있는 내용을 1~2문장으로 씁니다. 70~130자 정도를 편집 기준으로 삼되 억지로 맞추지 않습니다. 이는 검색엔진의 글자 수 제한이나 노출 보장이 아닙니다.
5. `date`는 최초 발행일입니다. 실제 내용을 고쳤을 때만 `updated: "YYYY-MM-DD"`를 추가합니다. 수정일은 화면·공유 메타데이터·사이트맵에 반영되며 최신 글의 발행 순서를 바꾸지 않습니다.
6. 긴 글은 기존 주제 전환에 맞춰 `## 소제목`, 필요할 때 `### 세부 항목`으로 나눕니다. 짧은 소식에 불필요한 소제목을 늘리지 않습니다.
7. 사진은 기존 폴더 규칙대로 넣습니다. `![제품 전면과 볼륨 노브](/posts/...)`처럼 실제 보이는 내용을 설명합니다. 이미지마다 글 제목을 반복하지 않습니다.
8. 관련 글은 같은 제품군·비교 대상·기초 설명처럼 독자에게 도움이 되는 문맥에 연결합니다. 링크 수를 채우기 위해 무관한 글을 넣지 않습니다.
9. 저장 후 `npm run content:check`, 배포 전 `npm test`와 `npm run build`를 실행합니다. 빌드 전에 원고 점검이 자동으로 실행됩니다.

## 분류와 리뷰 정보

- `category`: 기존 목록의 대문자 표기를 우선 사용합니다. 예: `DAP`, `DAC`, `HEADPHONE`, `TURNTABLE`, `LISTENING SPACE`.
- `tags`: 브랜드, 모델, 주요 주제를 중심으로 3~6개 정도를 고릅니다. `리뷰`, `기사`, `오디오 리뷰`는 이미 메뉴가 구분하므로 새 원고에서는 생략합니다.
- 같은 브랜드는 기존 표기를 재사용합니다. 전체 과거 태그의 통폐합은 별도 단계에서 기존 태그 주소와 연결을 확인한 뒤 진행합니다.
- 제품 리뷰: `reviewItemType: "Product"`, `reviewItemName: "브랜드 모델명"`.
- 공간 리뷰: `reviewItemType: "Place"`, `reviewItemName: "실제 공간명"`.
- 리뷰어 YK는 자동 표시됩니다. 별도의 author 입력은 필요 없습니다.
- 점수·가격·직접 측정 여부·대여/제공 관계는 확인한 정보만 기록합니다. 검색 노출을 위해 가짜 평점이나 경험을 추가하지 않습니다.
- 출처 기사와 작성자의 청음 경험을 구분합니다. 직접 듣지 않은 제품을 사용기로 표현하지 않습니다.
- 컬럼은 기존 `content/columns/AGENT.MD` 및 `WRITING_GUIDE.MD` 기준을 우선 적용합니다.

## 자동 점검 결과 읽기

- 오류: 잘못된 필수 값/날짜, 없는 이미지·영상 또는 내부 글 링크. 빌드를 중단합니다.
- 권고: 본문을 복사한 요약, 긴 요약, 소제목 없는 긴 본문, 반복되는 사진 설명, 일반적인 태그 등. 편집 판단이 필요하므로 빌드를 막지 않습니다.
- 전체 목록: `node scripts/check-content.mjs --json`.
- 도구는 사실 검증, 이미지 내용 판독, 외부 사이트의 현재 가격·일정 확인을 대신하지 않습니다.

세 글의 본문 문장·이미지 경로·순서·발행일·URL은 유지했습니다. 요약은 원고의 내용을 압축한 것이며 제조사 자료 전체를 새로 검증한 것은 아닙니다. 청음 조건이나 제공 관계처럼 원고만으로 확인되지 않는 정보는 추가하지 않았습니다.

132편 점검 결과: 경로/필수 값 오류 0개, 개선 권고 393건(글 수가 아니라 중복 가능한 항목 수).
일반적인 태그 129편, 일반적/반복 이미지 설명 115편, 소제목 없는 긴 본문 90편, 도입부와 동일한 요약 35편, 긴 요약 23편, 리뷰 대상 유형 검토 1편입니다.

전체를 일괄 자동 재작성하지 않고, 최신 리뷰·기사부터 묶어서 정비합니다. 다음 묶음에서도 문체, 청음 경험, 외부 인용과 사실관계는 보존합니다.

## 2026-10-19 최신 리뷰 10편 정비

앞서 정리한 PD5·천변풍경을 제외하고 발행일 순서로 키메라, BTE-9·이오스, MM-520, 이부키, 라이소닉, 벨벳 이어팁, 아프로디테 DAC, 프레스토 뮤직, SP4000T·클라루스, 무선 헤드폰 코덱 글을 정리했습니다.

각 글의 별도 요약, 주제별 H2, 일반 태그 정리, 실제 사진에 맞는 대체 텍스트를 적용했습니다. 관련 글을 언급하는 문장에는 필요한 내부 링크만 추가했습니다. 최초 발행일·URL·사진 경로 및 순서·본문 의견은 유지하고 `updated` 날짜를 기록했습니다. 제품 가격과 소프트웨어 기능 등 시간에 따라 바뀔 수 있는 원문 정보는 새로 확인하거나 고쳐 쓰지 않았습니다.
